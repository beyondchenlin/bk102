# 桌面最小闭环合同

日期：2026-11-08。状态：桌面最小实现已完成；[实际验收范围](copy-edit-desktop-mvp-report.md)另记，不以合同代替测试。

## 共享边界

- `ProjectSnapshot.schemaVersion = 2`，与之前只读接入样例 v1 分开。工程只保存素材 ID、SHA-256、流信息、实际 PTS 及裁切帧索引，不保存本机盘符或 URL。
- 主轨片段裁切为 `[inFrame, outFrame)`，索引指向解码后的展示顺序；`ptsUs` 以源首帧归零，末尾另存 `endUs`。不能用平均帧率推算 VFR 源边界。
- 画布首版固定 1080×1920、30 fps、SDR。编译时每段输出帧数由实际源区间向上取整；不足一帧的尾部保持上一帧。预览和导出使用相同计划，预览仅降低分辨率。
- 文案版本不可变，当前编辑副本另存。变更携带 `expectedRevision` 和 `operationId`；旧修订冲突拒绝，重复操作不能再写一版。
- 贴片是透明 PNG 素材，保留可编辑多行文字、颜色、描边与背景源。轨道顺序：贴片、字幕、叠加、主视频、配音、BGM。本轮可编辑主视频、贴片、配音和 BGM；字幕与任意叠加视频不伪装成已实现。
- 媒体接口：`capabilities`、`probe/import`、`frame`、`startRender(snapshot, profile)`、`job`、`cancel`。任务绑定工程修订和内容摘要，后来的修改不得污染已提交任务。取消只结束该任务创建的进程；未完成文件不能作为结果。
- 桌面提供方运行于 DSH Host 所在 Windows 机器。远程手机浏览器访问它，仍然是电脑编码，不称作手机本地导出。Android 提供方本轮不接入。

## 插件接入

延续 `dsh.bundle.patch`、`dsh.client`、Cordis 生命周期、`sidebar.panellist/main`、Typert Remote 和 tools。二进制上传/读取通过 DSH `connection.fetch.register`，由宿主既有 Host/Origin、认证和 owner Peer 门禁准入；不增加端口。插件私有数据位于 DSH_HOME 下独立目录，不读取宿主密钥。

## 界面计划

颜色优先使用宿主主题；浅色回退值：纸面 `#FFFFFF`、次表面 `#F5F5F7`、正文 `#202124`、次正文 `#60646C`、分隔线 `#DADDE3`、操作蓝 `#2459C4`。深色沿用 DSH token，不自造品牌渐变。

字体沿用宿主系统字体，中文使用系统中文无衬线；标题 24/600、正文 16/400、文案编辑 18/400、时间码 14 并开启等宽数字。正文左对齐，窄屏控制按钮最小 44px。

桌面：`侧栏入口 → 两块首页 → 文案（版本列表 | 编辑）/剪辑（预览 | 素材与裁切）→ 下方轨道`。
手机：同一路由，预览在上、当前镜头与逐帧按钮在下，素材和版本用可展开区；不把桌面三栏等比缩小。

审视后删去模板式仪表盘统计、介绍标语和每区重复卡片。保留用户要求的两块首页；工作页用空白、对齐和轨道位置表达关系。操作入口直接命名为保存版本、导入素材、替换镜头、预览、导出，不显示媒体引擎术语。

## 有界实施与验收

复用 E:/dsha 的现有插件依赖、独立 DSH runtime 和 E:/ffmpeg，不新建 worktree、不构建 DSHA APK。当前 C 30.72 GiB、D 16.78 GiB、E 79.07 GiB；D 低于 20 GiB，仅复用既有工具链。新媒体夹具与结果限定在 build/copy-edit-desktop；预计峰值低于 1 GiB，保留必要成片和报告，不复制旧模拟器证据。

验收包括版本重开与冲突、真实文件上传、非关键帧裁切与替换、整段连续预览、1080P 实际解码检查、取消与失败、真实 DSH 停启与认证、桌面及 320/390px 触摸布局。浏览器小屏验证不等于 Android 真机、系统返回、软键盘或本地编码通过。
