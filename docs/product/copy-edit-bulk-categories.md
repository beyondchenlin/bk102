# 桌面批量分类

2026-11-08，`dsh-copy-edit@0.2.0-desktop.26`。

## 交互

文案与剪辑区域各有“多选”。卡片右上和列表首列显示复选框，点击卡片／行主体也可切换选择，选择期间不进入编辑器。工具栏显示“全选当前结果”、已选数量、“设置分类”和“取消”。两区选择独立，卡片与列表切换保留选择。

“全选当前结果”只包含当前分类和搜索结果，不包括隐藏作品；再次点击取消全选。切换分类清空该区域的选择，搜索变化清空两区选择。空结果和未选择时禁用批量提交。取消、离开首页、刷新不会保存勾选状态。

批量分类窗口显示选中数量。原分类不同会要求明确选择目标；可以设置为预置／自建分类，也可以移回未分类。关闭窗口保留当前勾选，保存成功后退出该区域多选，另一侧选择保持。

## 实现边界

沿用已有认证 `copyEdit/library` Remote，增加 `assignCategories` 命令，包含 kind、projectIds、categoryId。单次接受 1–100 个不同的现存工程，校验整个集合与目标分类后，在既有 ProjectStore 单个事务中写入。一个批次只增加一次 library.revision，并复用 operationId 的幂等重放窗口及 expectedRevision 并发检查。

失败不会产生部分归类；修订冲突在窗口内提示刷新，刷新后重新提交。分类变更不进入工程修订、剪辑撤销历史或媒体计划，也不改变文案版本、镜头范围、文字、配音和 BGM。

改动限定在 categories.mjs/cjs、home.cjs、新增 bulk-categories.css、类型合同、构建注入和包版本／说明。`store.mjs`、编辑器主 client.cjs、媒体后端、工程命令、裁切、连续播放器、镜头排序、贴片手势及四区域布局文件的摘要均与本轮开始相同。没有修改 DSHA 宿主或接入 Android。
