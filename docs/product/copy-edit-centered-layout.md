# 文案页居中与自适应布局验收

日期：2026-11-08。插件版本：`0.2.0-desktop.27`。范围仅为桌面文案页；不涉及 Android 或 DSHA 宿主实现。

## 页面调整

- 正文与顶部操作栏共享居中内容列，最大宽度 1040 CSS px，随可用宽度缩小；正文保持左对齐、顶部对齐。
- 工具栏进入同一滚动容器并吸顶，按钮与内容栏右边缘对齐；窄窗口下自然换行与左侧排列。
- 正文输入框按内容与实际宽度自动增高、缩短，保留约三行的最小高度；取消超宽屏按视口高度撑开的正文区域。
- 正文与贴片区间距固定为 24 CSS px，保留多行透明 PNG 贴片、BGM 和完整示例工程入口。

新增 `src/copy-layout.css` 和 `src/copy-layout.cjs`，由现有构建脚本合入客户端。样式限定在文案页，自动高度只读取尺寸及设置输入框高度，不修改正文值。版本保存处理、分类、剪辑、裁切、配音绑定、预览和导出逻辑未改动。

## 验证结果

现有 60 项测试通过，零失败、取消或跳过；类型检查、构建和客户端语法检查通过。构建产物与本机已安装插件逐文件摘要一致。

实际浏览器检查了 3840、1920、1280 和 390 CSS px 宽度。内容列相对文案详情区中心偏移为 0，工具栏与正文边缘一致，无水平溢出。宽屏内容列 1040 px；1280 屏幕为 702 px；390 屏幕为 284 px。窄尺寸仅为浏览器布局检查，不代表 Android 验收。

交互验证使用单独工程“文案居中验收 · 窗边咖啡”：

- 长文自动增高，缩窄窗口后重新换行，滚动时工具栏吸顶；文末输入保持可见。
- 短文收缩至 114 px；实际键盘输入、保存 V2、切换 V1/V2、刷新后重新打开通过。
- 原有分类仍保留；首页分类筛选、列表切换、多选和取消通过。
- 打开既有“批量分类验收 · A”剪辑，复用已生成的 4 秒双镜头连续预览；播放至结束，120 帧、0 丢帧、无媒体错误。没有新增渲染任务，也没有重新执行完整 1080P 导出验收。
- 最后打开原有“桌面设计验收”文案 V2，保留给用户试用。

初始长文滚动脚本存在验证方式问题：物理浏览器视口比模拟视口大、超高输入框中心超出可见区域、光标已在文末导致 Control+End 不移动。后续使用可见坐标滚轮及 Control+Home → Control+End 真实输入完成验证。一次预览等待脚本参数位置错误，纠正为第三参数后取得播放完成记录。这些是验收脚本修正，不报告成一次连续全绿，也未因此修改业务实现。
