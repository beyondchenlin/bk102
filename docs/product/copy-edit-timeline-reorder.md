# 桌面镜头拖动排序

2026-11-08，最终插件 `dsh-copy-edit@0.2.0-desktop.24`。desktop.23 为首轮候选，desktop.24 增补拖出时间轴的取消边界；两个包和各自安装回执均保留。

## 交互与边界

桌面用鼠标拖动镜头主体调整顺序，两端继续用于裁切。移动超过 5 CSS 像素才进入拖动；显示拖动轮廓和插入线，按其他镜头中点决定插入前后。松手一次提交，主视频轨自动接续，不新增空白或更改源素材范围。

靠近横向边缘自动滚动。原位松手、Esc、失焦、取消指针或拖出时间轴均不提交；画布宽度变化与工程修订变化取消当前手势。前移／后移按钮保留；窄屏和触摸保持原操作。本轮不接入 Android。

绑定文字以稳定 clipId 计算新的有效时间区间，镜头内手调的起止时间保持；没有绑定的文字保持绝对时间。独立配音、BGM 的时间和素材范围保持。旧随镜头配音沿用已有规则：首次编辑将当前发声内容固定为独立配音。修改复用 `moveClip`、expectedRevision、operationId 和已有撤销历史；一次排序对应一步撤销。预览与导出按新修订重建。

实现仅涉及插件 `src/reorder.mjs`、`src/reorder.cjs`、`src/reorder.css`、`client.cjs` 接线、构建脚本和包版本。媒体后端、工程命令、存储、裁切算法、连续播放器、贴片拖动、首页和四区域布局文件相对本轮开始均未改变，摘要证据见 backend-baseline.json 与 media-audit.json。
