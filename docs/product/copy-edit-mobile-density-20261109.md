# 手机布局密度、两种尺寸截图与内置 APK

2026-11-09，最终插件 `0.2.0-mobile.17`。本轮按用户实机截图调整外观，保持白底、蓝色主操作；不操作生产手机、不修改既有用户工程。不创建工作树，不提交或上传。

## 调整依据与结果

首页原本让名称/分类、管理、多选/视图、新建在可换行容器中竞争宽度，手机上新建因此独占一行。现在按两行网格布局：第一行名称、多选、视图、新建；第二行可横滑分类和分类管理。卡片的字号、留白与空封面高度同步收紧。

剪辑预览原来有高度上限，而时间轴使用剩余弹性高度，导致 BGM 下方留下空白。现在预览接收剩余高度，时间轴按内容占位并在多轨时独立滚动；刻度按轴宽减少显示数量。文案独立标题继续移除，所有展示名使用正文首句，历史元数据不删除。

宿主本机固定 `dsh-web-mobile/src/client/styles/base.css.ts` 中有 36px 按钮、14px/20px 字体与 12px/17px 辅助信息，作为本地尺寸依据。没有找到可以声称为“Deepseek Harmony 官方设计规范”的独立规范；这里以实际 DeepSeek Harness 宿主为准。

参考 [Material 按钮规范](https://m1.material.io/components/buttons.html) 对视觉尺寸与点击范围的区分，以及 [Android 触摸目标建议](https://developer.android.com/guide/topics/ui/accessibility/apps)。Android 推荐 48dp 目标；本轮网页紧凑控件保留既有 44 CSS px 点击高度，部分视图切换按钮宽40px，不能宣称已全面满足48×48dp。透明边框是按钮本身的一部分，边缘点按实测有效。

| 元素 | 本轮取值（网页逻辑像素） |
| --- | --- |
| 顶部栏 | CSS 48px，含实际边框/设备舍入约49px |
| 剪辑底栏 | 图标文字同行，实测约49px |
| 主按钮底色 | 36px 高，实际点击高度44px |
| 视图/分类选中底色 | 32px 高 |
| 常规按钮/辅助信息 | 12–14px；图标17px |
| 文案正文 | 16px / 26px 行高 |
| 文案工具行 | 48px；进入剪辑为右侧紧凑按钮 |
| 页面间距 | 8/12/16px，区块间20px |
