# 桌面空格播放与可调工作区

2026-11-08，插件 `dsh-copy-edit@0.2.0-desktop.22`。仅修改插件桌面交互；未改 DSHA Android 宿主、媒体编码、工程存储与编辑命令。

## 行为

- 剪辑工作区内按空格播放／暂停，复用现有连续预览流程。输入框、多行文字、下拉框及输入法组合输入保留正常行为；按住空格不会反复切换；按钮获得焦点时不会在松开空格后误触删除。
- 素材库与预览、预览与属性区之间左右拖动；上方三栏与时间轴之间上下拖动。保留最小操作尺寸与面板内滚动，预览按 9:16 等比缩放。
- 双击分隔线恢复该方向默认值；拖动中 Esc 取消，窗口失焦或尺寸变化取消未提交拖动。分隔线支持键盘方向键，Shift 加大步长，Home/End 到达尺寸边界。
- 布局保存为当前浏览器、当前来源的 `dsh-copy-edit.editor.layout.v1`，不会进入工程、撤销记录或媒体计划。同一来源刷新可恢复；换端口或浏览器不共享。
- 窄屏沿用既有纵向布局，隐藏分隔线。返回宽屏恢复桌面偏好。本轮仅验证浏览器尺寸变化，不代表 Android 原生接入或手机性能验收。

## 实现边界

`src/editor-layout.mjs` 负责纯尺寸计算，`src/editor-layout.cjs` 管理手势、焦点与浏览器偏好，`src/editor-layout.css` 负责工作区网格。`client.cjs` 接入包装组件与空格事件，已有主页和编辑器内容复用。

相对本轮开始，`desktop-media.mjs`、`project.mjs`、`store.mjs`、`timeline.mjs`、`preview.cjs`、`trim.cjs`、`sticker-gesture.cjs` 均保持 SHA-256 一致。

## 实际验证

证据目录：`build/copy-edit-desktop/desktop-layout-20261108/`。

- 50 项测试通过，无失败、跳过；类型检查、构建及已安装文件摘要检查通过。
- 真实浏览器三条分隔线分别调整 120、100、120 CSS 像素，取消、单边复位、最小预览宽度及刷新恢复符合预期。
- 3840×2009、1920×1080、390×844 浏览器视口检查；插件无横向溢出，画面保持比例；窄屏返回后布局偏好未被覆盖。
- 空格开始、暂停、恢复及结束后重播通过；焦点位于删除按钮时不误删；贴片文字中输入空格不播放，按住按键不反复切换。
- 在调整后的工作区把首镜头从 150 帧拖到 120 帧，撤销恢复 150 帧。独立配音不截断；绑定贴片的有效结束帧随镜头为 120，撤销恢复。绑定贴片按当前镜头解析有效区间，不能用旧绝对时间字段单独判断。
- 实际连续预览完成 8 秒，浏览器本次报告 240 总帧、0 丢帧；仅为本机有限样本，不外推普遍性能。下载导出为 1080×1920、30fps、240 帧、8 秒。360×640 预览代理与导出音频解码哈希相同。
- 旧 15 个工程未变；23 个素材及旧 49 条结果保留。本轮增加 1 个演示工程、3 条预览／导出结果。45 个原有宿主改动文件未被本轮修改。

浏览器自动化不是一次连续全绿：一次使用了不存在的工具栏选择器；一次误把“导出”当成自动下载而等待超时，页面实际已完成导出，随后点击“下载视频”成功；媒体审计曾错误断言绑定贴片的旧绝对字段，改为检查有效解析区间。以上均为验证脚本纠正，未修改媒体实现掩盖失败。各轮脚本留在证据目录。
