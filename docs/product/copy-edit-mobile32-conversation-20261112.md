# mobile.32：确认文案后自动生成剪辑草稿

2026-11-12，承接 mobile.31。按[修订后的产品规则](conversation-to-edit-20261112.md)实现：用户明确要做视频且接受完整文案后，直接生成；只改文案或只保存时不启动视频任务。日常流程不再要求复制选片信息、粘贴计划或输入素材库口令。

## 已实现

- 注册 `copy_edit_context`、`copy_edit_confirm`、`copy_edit_task` 三个真实 DSH 工具，分别处理创作上下文、文案确认和任务控制。工具说明要求辨别本次意图及整篇确认，不能把普通文案讨论或含糊的“好”直接当作制作视频指令。返回排队状态不等于成片完成。
- 保存文案版本和分类；生成固定绑定该确认版本及声音、音乐、原声偏好。默认值齐全时直接执行，缺少时集中询问；只有明确要求记住才保存长期偏好。明确“不加音乐”优先于部署默认音乐。
- 宿主连接素材库和固定配音服务，凭据不进入工程、对话工具返回值或浏览器存储。一次部署连接后，由宿主传递计划和授权；真实连接不随 APK 发布。
- 按句生成实际 WAV，媒体登记读取真实时长，再请求素材计划、下载并核验原片身份，生成可编辑首句标题，原子提交视频、贴片、旁白和 BGM 轨道。
- 对话页常驻执行器与文案库“生成视频”共用同一入口；关闭剪辑面板后仍可在对话页执行。已有结果再次点击生成直接打开同一工程，不重新配音，也不覆盖后续手动剪辑。
- 任务、阶段回执、租约和缓存持久保存。多页面不重复领取有效租约；暂停与提交在同一存储锁下校验。非幂等配音服务回执不确定时不自动重复合成；服务确实支持幂等时使用稳定请求键。
- 手动导入保留在“更多 → 高级导入选片”，供兼容与排障。文案库不重复显示生成工程的正文副本。

代码位于 `plugins/dsh-copy-edit`，插件版本 `0.2.0-mobile.32`。原生媒体实现沿用 mobile.31；没有修改生产 DSHA 身份或正式包。部署约定见[创作连接契约](../../plugins/dsh-copy-edit/contracts/creation-connections.md)。

集成文案为“厨房货架摆放整齐。街边小吃摊热闹起来。”。两次配音分别为 1.97 秒、2.16 秒，按 30fps 安排 60 帧和 65 帧，共 125 帧；2 镜头、2 旁白片段、1 首句标题、1 默认 BGM，无选片警告。BGM 是隔离验收音频，不代表已建立生产音乐库。每句不足一帧的尾部补空隙，没有截断语音。

桌面时间线截图保留于本轮目录。末轮窄屏截图遇到 Ego 窗口最小化，恢复窗口 API 未成功，因此窄屏只记录 DOM 和几何证据，不写成像素截图通过。最终已关闭 TaskSpace 15。

原始失败与纠正：首次回归未提供已有 FFmpeg 路径导致 6 项实际媒体测试失败，修正环境后完整通过；素材库首次启动同样缺少 FFmpeg 路径，隔离服务收尾后修正重启。APK 首轮误用缺少 Android 插件的 Gradle 缓存，次轮缺少 Python 命令，切回已有可用缓存并显式设置 Python 后通过。浏览器发现同版本同路径安装包被 pnpm 缓存，改为摘要命名并核对实际安装字节；修正进度提示反复替换 DOM、重复生成未直接打开结果等问题后重新打包和验证。以上不是一次连续全绿。

## 明确保留的范围

自动选片目前最多 900 帧 / 30 秒、32 句、每句 200 字，总文案最多 6000 字。超限保留原文并说明问题，不静默裁掉。普通剪辑的 10 分钟能力不代表自动选片已支持 10 分钟。

当前生成首句标题，不包含完整逐字字幕。参考音频克隆、任意已有整段旁白自动对齐、自然语言精细修改镜头工具尚未实现。模型意图由工具说明约束，本轮验证了实际工具调用，没有运行真实聊天模型完成端到端对话，不能据此宣称所有自然语言表达都能正确识别。

正式服务需在桌面或手机可访问的宿主环境部署一次连接。退出整个工作台后不保证继续执行，重开可用页面后按持久阶段恢复。手机上的原生桥、远程服务可达性及性能仍待真机验证。本轮没有新增 Linux 运行证明或新里程碑 tag；此前素材库 Linux 验证及其 tag 仍按历史范围阅读。
