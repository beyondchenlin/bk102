# 文案工作台 B 方案（2026-11-08）

交付版本：`dsh-copy-edit@0.2.0-desktop.34`。安装于既有隔离 DSH Home，未修改 Android 或 DSHA 宿主实现。

## 界面与操作

- 文案正文占主区，名称用于列表检索与版本管理。复制按钮突出，只复制正文；保存与历史版本合同保持。
- 配音和背景音乐放在正文下方。常用音乐按工程使用次数显示前三项，保留完整选择、上传，并增加真实试听。
- 右侧统一为「剪辑工程 / 文字贴片」。工程显示实际素材、已保存的贴片，可连续播放并进入现有完整剪辑页；贴片页保留多文字、透明 PNG、颜色及保存。
- 默认 9:16，16:9 只切换预览容器，当前导出仍为 1080×1920。切页停止音频，回到工程页恢复首帧，不留下旧播放位置。
- 内容区最大 1800px、预览栏最大 440px，防止 4K 屏竖屏画面过高。缩窄时重排，不改变工程画幅。390px 仅做网页排版检查，不代表 Android 原生验收。

## AI 配音的边界

公司服务、自有 API 分别保存服务地址、模型、音色库；逐文案保存来源、音色与语速。添加音色支持服务音色 ID 或参考音频（不超过 60 秒、20 MiB），参考音频可试听。

这次完成配置与交互入口，**尚未接入任何 TTS 适配器、音色克隆或在线音色目录**。生成按钮明确不可用；不收集 API Key、不发送参考音频到公司或互联网服务。参考音频不进入成片音轨，既有配音/BGM 继续按原规则渲染。API 鉴权与服务协议需在后续具体接入时实现，不能把普通聊天 API 当作语音生成接口。

配置使用独立修订、幂等请求与既有 `ProjectStore.write`，不增加工程修订、撤销记录或渲染缓存失效。旧库只读不写迁移。失败显示具体错误，冲突可重载设置；取消不保存配置。配置只经 DSH 已认证 RPC 读写，不开旁路端口。

## 验证中的修正与限制

本轮不是一次连续全绿：首次取鉴权文件早于服务就绪；一次 localhost 页面请求等待未返回，使用启动器新的 127.0.0.1 鉴权链接恢复，未推断或修改宿主网络。初版超宽屏预览过高导致控件难操作，`.33` 限宽后实际保存通过；`.34` 修正切换预览标签后的旧位置与窄栏按钮折行。

若干自动化步骤因选择器/快照参数不符而中断，观察现场后从断点继续。审计最初错误地要求整个分类库完全相同，忽略了脚本明确创建示例时的分类归属；改为核对「原库 + 唯一示例归属 + 一次修订」后通过，没有修改原分类数据。DSH 插件安装仍报告由宿主提供的 peer dependency 警告，实际宿主装载与上述运行验收通过。

只重跑变更相关范围，没有重新跑 60 秒性能矩阵、Android 或外部语音服务。媒体编译/裁切/编码算法均未变。
