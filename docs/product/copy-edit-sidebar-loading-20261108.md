# desktop.35：文案列表调宽与载入等待保护

日期：2026-11-08。范围仅为 `plugins/dsh-copy-edit` 的桌面文案界面与只读载入；不涉及 Android、DSHA 宿主实现或媒体引擎。

## 行为

- 文案列表与正文之间增加 8px 可操作分隔条。拖动左右改变列表宽度，正文和右侧预览沿用现有自适应布局。
- 默认 280px；可在 200–720px 内调整。窄窗口进一步限宽，为右侧保留 420px 正文和 8px 分隔条；回到宽窗口恢复原偏好。工作台宽度不超过 760px 时隐藏分隔条，沿用列表/正文切换。
- 宽度只保存到当前浏览器的 `dsh-copy-edit.copy.sidebar-width.v1`，不写工程、版本、分类、撤销历史。双击重置，左右键每次 10px，Shift 每次 40px；Home/End 到边界。Esc、失焦、指针取消和拖动中窗口缩放取消未提交操作。
- 工作台只读请求最多等待 12 秒，包括等待响应正文。失败显示错误和“重新载入”；退出工作台取消未完成读取。不自动重发保存、分类、裁切、渲染或导出命令。
- 401/403 显示重新打开完整鉴权链接的提示；不修改鉴权机制。

## 加载诊断的实际边界

用户已确认原来“正在载入”的情况恢复，原始停顿现场未取得完整网络记录，不能认定确切根因已修复，也不能宣称普遍提速。

本轮本机认证读取工作台接口两组耗时分别为 39/7/8ms、43/7/8ms；25 个工程、25 个素材，工作台响应约 100KB。较早 IAB 网络记录为 HTTP 200，响应头约 15ms 到达。这些仅是当时本机小样本。

Ego 验收浏览器后来出现独立的网络等待：工作台读取、普通 manifest GET 和 XHR 均可等待至截止；Node 直连和 IAB 中同一服务正常。观察到同源打开了 6 个页面，但没有证据证明标签数或连接池耗尽就是原因；不据此修改宿主、不关闭用户旧页面。无 Service Worker 注册，绕过缓存/Service Worker 的临时对照没有解除等待，设置已还原。Ego 任务页最终关闭，用户体验页保留在 IAB。

## 两轮 review

### 第一轮：代码和数据边界自查

检查只读超时、AbortController 清理、卸载取消、晚到读取、拖拽捕获及取消、宽度持久化边界。校正了超时分支的顺序：先拒绝等待 Promise，再中止 fetch，使 fetch 的 AbortError 不覆盖有用的超时信息。

复用现有依赖和 FFmpeg，构建、类型检查、生成客户端语法检查通过。72 项测试通过、0 失败、0 跳过；其中新增 7 项覆盖读取截止/取消和宽度边界，其余为原有分类、版本、剪辑、贴片、配音及媒体检查。实际 FFmpeg 路径通过既有环境变量传入，未安装另一套运行环境。

### 第二轮：浏览器操作与安装结果复查

- IAB 真正拖拽：列表 280→460px；左键微调为 450px；拖动后 Esc 取消恢复 450px；双击恢复 280px。
- End 到 720px；1280px 窗口下列表限为 572px、正文 420px，无横向溢出；放大后恢复 720px；刷新并重新打开文案后仍为 720px。
- 390px 视口隐藏拖拽条，无页面横向溢出。此项只验证网页断点，不属于 Android 验收。最终恢复默认浏览器窗口，体验页列表宽 400px。
- Ego 中注入单个挂起的只读请求，约 12002.9ms 超时、调用一次、中止一次，无自动重发。随后真实请求在该浏览器仍等待，此失败保留，不写成重试通过。
- IAB 中注入相同挂起情形，观察到超时提示；还原原生 fetch 后点击“重新载入”，成功显示并搜索工作台。中途 UI 自动化等待工具在约 4 秒提前退出，后续观察确认产品在截止后显示错误；该工具等待失败不是产品已通过的证据。
- 另测载入中退出工作台：调用一次、中止一次。临时 fetch 包装均在 finally 中还原，未留网络拦截或模拟数据。
- 安装的 14 个 lib 文件逐字节匹配构建结果。原 32 个插件源码中 30 个保持不变；仅 `client.cjs` 与 `copy-layout.css` 有变化，另新增独立模块。客户端裁切及 EditPage 代码块、版本保存入口保持逐字节一致。
- 现有 305057 字节用户状态文件与本轮开始时 SHA-256 完全一致，包含用户此前自行修改的 B 方案 V3 正文；没有回滚或重置这些内容。45 个既有宿主修改文件摘要不变。

本轮没有重新执行整套用户素材 UI 导出；媒体引擎代码未修改，原有自动媒体回归通过。安装时 pnpm 保留宿主提供 peer 依赖的既有警告，实际 DSH 插件载入已验证。
