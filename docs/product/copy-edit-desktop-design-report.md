## 依据与结果

已找回 2026-11-07 最终六图，桌面采用 D1 首页、D2 文案、D3 剪辑。目录、图像摘要及参数见[设计基准](copy-edit-desktop-design-baseline.md)。保留原图，未重新生成；后来“贴片是多行透明 PNG”的纠正继续有效。

desktop.2 的验收是功能闭环，不是视觉验收。此次恢复首页上下两张内容卡片；文案列表与正文并列，提供搜索、新建、版本、复制、保存和打开剪辑；贴片与 BGM 在正文下方，样式编辑按需展开。深色剪辑区采用素材库、预览、镜头属性三栏，下方全宽时间轴。源帧按钮、首末帧、替换、调序、声音和导出继续使用同一工程服务。

时间轴片段按实际时长排列，支持缩放、定位及连续预览播放头。保存的透明 PNG 在静帧和成片中读取同一资产。新建空白工程使用正式 Typert Remote 服务，带操作标识和确定工程身份，保留旧工程，不修改运行中的 JSON 文件。

原图中的咖啡素材、AI 修改、业务分类、字幕、叠加和音频波形不伪装成已有能力。验收视频是自制色块和帧条码。字幕/叠加保留空轨并标明暂未开放；裁切使用首末帧与逐帧按钮，未实现拖拽裁切手柄，也不是实时多轨合成引擎。

## 失败与修正

首次客户端嵌套括号语法失败，拆出素材项构造后通过。新建测试误把同步参数拒绝写成异步拒绝，修正断言后通过。页面启动早于认证文件生成，等待 ready 后恢复。候选截图发现标题样式被通用选择器覆盖、短片刻度重复及跨镜头定位被初始化覆盖，修正后在 desktop.4 复核。安装器保留宿主提供的 peer dependency 提示，实际 Host 加载及调用成功；不称日志无警告或一次全绿。
