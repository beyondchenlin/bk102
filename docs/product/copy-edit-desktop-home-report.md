## 实现范围

按本聊天确认的两张首页效果图，上方展示文案，下方展示剪辑工程。两个区域分别选择卡片或列表，选择保存在当前浏览器来源的 localStorage；切换其中一个不会改变另一个。内容占用插件可用宽度，卡片随宽度换列，列表在窄窗口收起次要列。

首页直接使用已有工程：文案显示标题、正文摘要和版本；剪辑显示实际素材封面、标题和时长。支持全文搜索、新建、直接打开，以及更多菜单中的文案／剪辑互相进入和复制文案。返回首页保留当前搜索与滚动位置。没有使用效果图中的虚构咖啡封面替换真实素材。

新增可选 `updatedAt` 元数据，只在新建或合法编辑时写入，读取旧工程不补写。缺少可靠时间的旧记录显示“—”。媒体计划不包含该字段，时间变化不会让同一媒体计划失效。

首页组件与样式分别放在 `plugins/dsh-copy-edit/src/home.cjs` 和 `src/home.css`，通过既有构建内联。现有编辑器、拖拽裁切实现及媒体管线保持原样；相对本轮开始时的 desktop.6，`EditPage`／裁切 UI 区块、`desktop-media.mjs`、`store.mjs`、`trim.cjs` 和原 `client.css` 的内容核对一致。

## 过程中的问题

浏览器最初使用 `127.0.0.1` 时请求等待，同期 Node 鉴权请求正常；同一页面改用 `localhost` 的有效启动链接后恢复。尚未证明具体原因，不归结为插件或浏览器的确定缺陷。最终试用链接使用 localhost。

第一版卡片在常用桌面宽度排了五列，随后调整最小卡片宽度至 320px，在 1920px 宿主页面排四列。一次自动化使用了不支持的定位表达式，另一次大视口点击失败；修正验收定位和测量顺序后继续。原始失败文件保留，不称一次全绿。
