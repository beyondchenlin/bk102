## 实现设计

- 宿主侧栏及聊天不改；插件占满宿主提供的主面板。首页上下两卡，带真实最近内容；文案页和剪辑页不再受 1100px 居中容器限制。
- 文案页：固定宽度的检索列表 + 可伸缩详情。正文以文档形式编辑，版本入口紧邻标题；贴片和 BGM 在正文下方。透明 PNG 是图片，样式修改按需展开，不把所有颜色表单常驻在右侧。
- 剪辑页：深色工作区；左素材、中预览、右镜头属性；下方全宽时间轴。素材缩略图来自实际导入的视频，片段宽度表达时长，时间尺与播放头对应工程时间。
- 轨道顺序：贴片、字幕、叠加、主视频、配音、BGM。未实现的字幕/叠加保持空轨并明确不可编辑；不伪造音频波形，不把真实源帧变成装饰图片。
- 保留已验证的版本保存、导入、裁切、替换、连续代理预览和导出媒体接口。补可用的新建空白工程入口，不覆盖已有项目。
- 尚未接入模型/公司服务，故不放能点击却不工作的 AI 修改、服务器检索按钮；不把分类示例硬编码成真实业务数据。

## 视觉参数

白色 `#ffffff`、列表背景 `#f7f8fa`、正文 `#191c22`、次要文字 `#747985`、操作蓝 `#376bfa`、浅分隔 `#e6e8ec`；剪辑区用 `#191b20` 与 `#24272e` 分层，保持宿主原主题。字体沿用系统中文无衬线，标题 28–32px、正文 18–20px、操作 14–15px，时间数字使用等宽数字。

```text
首页：宿主侧栏 | 标题 / 文案卡片 / 剪辑卡片
文案：宿主侧栏 | 列表、搜索、新建 | 版本、正文、贴片、BGM
剪辑：宿主侧栏 | 素材库 | 预览、逐帧播放 | 镜头属性
              | 全宽时间轴：贴片 → 字幕 → 叠加 → 视频 → 配音 → BGM
```

对照评审：选择上述白色文案与深色剪辑是原图明确决定，不新增宣传区、渐变或统计卡片。首页允许控制阅读宽度，不能由此限制编辑工作台。宽屏验证采用实际运行截图，另做窄屏回归；不以“没有横向溢出”替代视觉符合性。
