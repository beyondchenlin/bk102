## 多轨分割

选择视频、文字贴片、配音或BGM，定位工程播放位置，点击分割。删除同样作用于选中类型。各分割命令支持撤销、重做、重开；边缘和无效位置拒绝，不产生空片段。选中音乐或配音时属性区直接展示对应片段。

文字保留图像、样式和相对镜头绑定。配音保留源入出点；旧整段配音分割时保持原工程可见时长，不引入隐藏的长尾。BGM以48kHz采样偏移保存循环相位，每帧1600采样，右段不会从音乐开头重播。文案页显示分段音乐状态并可进入剪辑调整；主动重新选整段音乐仍采用原替换操作。

新音轨采用冻结计划schemaVersion2，原生能力增加segmentedAudio。旧原生提供方明确提示升级，不静默忽略音轨。连续相邻音乐可在渲染计划中合并；原生连续配音只有源区间、工程时间和音量均一致时合并解码。UI分段继续保留。真实间隔、重叠、不同音量不会合并。原生分段音乐使用有限片段序列，支持源尾到源头循环；保留512个执行片段上限及既有CFR30、混音增益等范围限制。

## 两轮复核及结果

第一轮检查尺寸、状态及工程模型，修正44px历史规则覆盖、旧整段配音转换延长工程、音轨选择/删除与镜头属性混用的问题。第二轮检查实际声音及界面行为，发现原生独立解码分割配音改变波形，增加连续源合并执行；最终基线对照PCM逐采样相同。

- 插件105项测试通过，0失败/跳过，含真实FFmpeg预览与1080P导出、25fps视频分割回归、BGM循环相位、声音左右声道、三轨撤销重做/持久化。早期运行104通过/1失败为旧状态文案断言，修改断言以验证只有未保存时显示状态后通过；另有新测试误用store方法的失败及纠正。
- Android相关原生10项同次通过，新增音乐源尾循环1项另跑通过。包括原生计划边界、取消/后台、音频尾部黑帧、真实预览/导出、分割配音基线及连续源合并的负控。非一次连续全绿。
- 原生配音分割与基线均解码189888个采样，最大误差0。这个基线不是采样精确收尾证明：4秒视频的原生历史基线仍有约44ms音频尾部缺口，属于播放/尾音精度待验范围。本轮不据此宣称原生声音全时长精确。
- 原生分段音乐预览/导出及源尾循环：删除区间峰值0，两声道相位相关系数至少0.999916；共同编码偏移12采样（250µs）。初始零偏移对照0.9437的失败推动了有界偏移诊断，未直接放低相位阈值。配音旧失败数值maxError0.060906/rmsError0.009098来自工具回执；早期PCM文件已被后续复测覆盖，不将其冒称原始失败音频保留。
- Android界面 `narrow-123449`：实际选择BGM、配音和贴片，分别分割、撤销、重做；每类最终两段，页面无错误。仅本轮临时工程参与写入。
- Ego37：桌面四区/三分隔线、三种分割往返、选中音轨属性验证通过；已finish，无保留标签。
