## 实现范围

侧栏「文案剪辑」→ 两块首页 → 文案/剪辑，未向每个对话加业务按钮。文案保存 V1/V2，可读取历史内容并另存新版本；工作台内部切页保留草稿。手动选择真实文件上传并索引源帧；支持首末帧、前后逐帧、裁切、替换、移动和删除镜头。多行文字由 Canvas 栅格化为透明 PNG，包含颜色、描边和可选背景。配音与 BGM 可选导入文件。新手入口创建可编辑示例副本，包含两段自制色块、PNG、提示音和文案；不冒充真实案例或 AI 配音。

预览和导出读取同一冻结计划。先生成 360×640 代理，浏览器单播放器从当前镜头/位置连续播放后续片段；这不是实时多轨解码。导出 1080×1920、30 fps、H.264/AAC，成功后才提交成片并提供下载。取消不会覆盖上一份成功结果。

## 发现与修正

首轮媒体脚本同时提交 5 个导入，命中实现的 2 路限额；改为串行测试，保留失败报告。微秒取整可能把单个 33334us 源帧误当成两帧，已加 1us 量化容差并通过真实单帧读回。文案未保存时切页丢草稿，已在工作台保持草稿；切页重置滚动，避免标题被固定返回控件遮挡。

浏览器的首次登录弹层、隐藏文件 input 等等待失败与产品失败区分。窄屏模拟必须同时启用 coarse pointer/touch，只有改宽度仍可能显示桌面侧栏；初始截屏捕获过空白过渡，原件保留，稳定证据单独命名。没有为小屏验证修改宿主侧栏或移动插件。

## 尚未覆盖

- Android 原生媒体接入、设备文件授权、Surface、系统返回、软键盘、后台编码、真机性能均未在本轮验收。手机浏览器连 Windows Host 时仍由电脑编码。
- 当前仅竖屏、SDR、总时长 60 秒以内；源视频原声静音，声音来自导入的配音/BGM。字幕和任意叠加轨仅保留布局，没有实现完整编辑功能。
- 公司索引、TTS、模型修改、团队同步未接入。没有会员系统。
- 代理预览需要准备时间；没有实时全轨预览或性能支持矩阵。测试素材为自制低复杂度样本。
- 关闭插件或刷新前仍需保存版本；未保存草稿只保证工作台内部切页。旧移动宿主的系统返回仍可直接退出插件，通用子路由返回留在独立宿主接入范围。
- 版本/素材/工程/成片数量有界，暂未提供库清理界面。异常进程退出遗留的 writer.lock 会拒绝再次写入，需要核验后恢复，不自动删除未知锁。

## 隔离与收尾

复用唯一工作树 `E:/dsha` 和已有隔离 DSH runtime；新增工作树 0。45 个原有宿主修改文件与开始时 SHA 完全相同，未构建或安装 DSHA、未操作 Android 模拟器、未提交/推送/发布。

测试浏览器 TaskSpace 7 已关闭；独立 DSH 已正常停止，认证临时文件和停止请求已删除，writer.lock 释放、incoming 为空。单测临时 store 已自动回收；保留最小失败报告、成片、源素材副本、必要截图和复现脚本。桌面证据总逻辑体积约 46.6 MiB；保留既有运行环境供复用，不删除旧 Android 证据。

本轮前后可用空间 C 30.72→31.01 GiB、D 16.78→16.78 GiB、E 79.07→79.00 GiB；其他进程可能并发写入，变化不是本任务净释放量。D 低于 20 GiB，本轮仅复用，没有向 D 安装新工具链。
