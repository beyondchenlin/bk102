# 素材库选片接入 BK Harenss

本轮把素材库已保存的逐句计划交给 BK 生成新候选工程。素材库复制不含口令的计划编号、版本和来源原点；BK 页面输入素材库独立口令，选择配音和背景音乐，再通过既有 DSH 认证通道逐个登记选中的原视频、文字 PNG 和音频。BK 在已登记的真实 PTS（播放时间戳）索引上映射裁切，检查能力、准备并原子提交工程及回执。原来的工程、素材库和源文件不受覆盖。

素材库跨源读取默认关闭，管理员需要显式配置允许的 BK 网页原点；远程来源使用 HTTPS，本机回环允许 HTTP。选片版本、来源授权、理解版本、原件身份和完整摘要在传输前检查。恢复记录先保存在浏览器本地，不包含素材库口令；重试先查同一操作回执，票据过期只能对冻结内容重新准备。不能持久保存恢复记录或浏览器缺少 Web Locks 时，不开始不可安全恢复的提交。详细部署参数见素材库仓库 `docs/architecture/bk-media-bk-import.md`。

主视频保持计划的逐句帧数，不以平均帧率猜真实源边界；无合法范围明确失败。名称冲突、帧边界量化差和缺口保留为导入时提醒，替换画面之后提醒仍是历史提示，需重新核对。缺口工程不能编译为完整成片。素材库导入工程替换镜头时，新素材不足原镜头时长会拒绝并保留原镜头；旧工程的既有替换行为保持兼容。

## 隔离实测

只读核验七个原视频后，在任务独占库中使用副本和已有 Qwen3-VL-4B 原理解结果，没有重新推理或下载视觉模型。实际页面导入七个不同镜头，帧数 126、125、126、131、123、132、137，共 900 帧／30 秒；第 2、4 段合法出点分别比计划微秒值早 1 微秒。第 7 句保留“文案羊蹄／模型标注鸡爪，品类待核对”。

配音使用本机已有 OmniVoice 权重在离线模式生成的 17.36 秒语音；BGM 是本轮生成的 8 秒合成旋律测试夹具，不作为商业音乐交付。贴片为实际 PNG。经过真实素材库接口、BK 桌面媒体登记和草案处理器，工程包含贴片、7 个主视频镜头、独立配音和循环 BGM。响应丢失恢复测试与真实重复查询均返回同一工程，不覆盖后续编辑。

在实际网页编辑器中换镜头；修改贴片文字为“夜市探店记录”、位置及第 31—450 帧显示范围；调整配音起点、源范围和音量以及音乐起止和音量。主视频分割、撤销、重做后为 8 段且仍为 900 帧。刷新、重新打开剪辑后，四轨与修改值保持；浏览器预览已播放并解码音频。九个原视频及工程引用媒体的摘要再次核验一致。未做语音逐字识别准确率评测、真实手机播放或功耗验收。

## 两轮串行审查

两轮由同一执行者完成，不是独立多人审查。

1. **身份、事务和恢复**：补充计划与来源在提交前复核、媒体完整摘要、有界读取、冻结请求先持久保存、超长配音在冻结前拒绝、回执与操作／票据身份比较；增加错库、过期版本、来源内容变化、丢响应、票据过期、损坏恢复记录和正文缺句的测试。
2. **页面、时间轴和四轨**：真实编辑发现短素材替换会让 900 帧变为 899 帧；对素材库候选增加不足时拒绝并保留原镜头的保护。补充导入时提醒、名称冲突优先展示、媒体名称、导入中返回保护和卸载时取消读取；重复真实服务往返确认仍为七镜头、四轨和 900 帧。
