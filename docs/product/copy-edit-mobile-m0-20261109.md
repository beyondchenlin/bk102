# M0 字号与控件实测

2026-11-09，既有 DSH 0.2.1-rc.2 / desktop.35 开发同步。同一 Ego Chromium、100% 页面缩放（visualViewport.scale=1），截图对照统一为 1440×1000 CSS px。3840×2160 单独检查宽屏字体不再增大。390×844 只是网页布局检查。

字体读取宿主 `--dsw-font-family`，回退 `--dsh-font-family-text-default`；局部定义 UI 14/22、次要13/20、元信息12/18。所有新增选择器限定 `.dce`，没有覆盖宿主CSS、修改浏览器缩放或更改Canvas贴片渲染。原CSS中超宽规则和B方案的容器字体曾互相覆盖；当前由独立 `ui-scale.css` 统一最终层级，不再随容器放大。布局宽度、B方案与桌面四区分隔条保持。

表单select的computed line-height在此Chromium仍返回`normal`，不虚报成22px；实际外框高度桌面36/38、手机44。手机44px检查覆盖导航、复制、保存、版本、声音选择和预览标签；时间轴手柄与触摸冲突在M1单列。

证据位于 `build/copy-edit-mobile/20261109/`：`fonts-before.json`、`fonts-after.json`、`host-fonts.json`、`host-panel-fonts.json`，`before/after-home-1440.png`、`before/after-copy-1440.png`。最早`host-1440.png`采样实际为1912宽，未用于同视口对照；发现Ego跨轮次清除CDP viewport设置后，所有正式对照在每轮内设置并读回1440宽。

构建、TypeScript编译、生成客户端语法检查通过；同步前核对已安装客户端与原lib摘要一致，随后仅同步本次client，由已有HMR加载。未写文案版本、工程或媒体结果。M0不是手机全部目标完成；继续M1状态、返回和触摸，再进入M2媒体。
