# 文案附件与桌面剪辑工作台整理

2026-11-08，交付版本 `dsh-copy-edit@0.2.0-desktop.31`，沿用现有 DSH 插件注入与服务合同；没有 Android 原生接入或宿主实现修改。

## 界面与边界

- 文案内容列仍水平居中、顶部对齐、正文左对齐。复制文案为主要按钮，成功显示“已复制”；仅复制正文，不带名称。名称继续用于列表、搜索与版本识别，不删除原数据。
- 文字贴片、背景音乐、剪辑工程为等宽同级三列，标题和预览顶部对齐。贴片与工程封面共用 9:16 / 16:9 预览画幅，默认 9:16；画布占满栏宽，没有原来的固定高度外框和两侧填充。音乐区域同高，空间不足时内部滚动。
- 常用音乐按当前各工程的 BGM 引用次数排序，最多六项；其余音频可在“全部背景音乐”选择器选择，保留“不使用音乐”。上传按钮直接导入并选用音频。没有引入历史点击统计或新数据结构；未被用作 BGM 的音频排序在后。
- 有镜头时“打开完整工程”打开当前文案对应的现有工程；无镜头时提供“创建示例工程”，仍使用原教学示例创建流程。
- 预览画幅只是文案页展示选择，不改工程坐标或导出参数；实际导出仍是 **1080×1920 / 30fps**，不是新增横屏导出。
- 桌面剪辑页统一深色表面、按钮层级、文字和间距；时间轴工具按撤销/重做、分割/删除、入出点、文字分组。移除没有编辑能力的字幕和叠加占位轨，保留贴片、主视频、配音和 BGM。
- 原三条分隔线继续调节素材库、预览、属性、时间轴四区；快捷键、裁切、分割、替换、重排、贴片联动、配音与渲染逻辑保持原实现。容器缩窄时附件改为上下排列，没有新依赖。

主要实现：`plugins/dsh-copy-edit/src/copy-tools.cjs`、`copy-layout.css`、`editor-polish.css`、`client.cjs`、`scripts/build.mjs`。新增工具仅处理展示、复制和调用现有上传/编辑命令。
