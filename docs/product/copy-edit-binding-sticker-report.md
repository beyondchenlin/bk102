## 边界与保全

当前只有一块全工程PNG文字贴片，不提供多文字层、独立文字时间段、字幕编辑或字体库。逐镜头配音依靠人工指定音频源范围，不自动识别语音边界；软件保护所选范围完整，但不能判断用户是否把边界选在字音中。“试听此句”为浏览器音频试听，结束事件有播放器调度粒度，最终渲染使用采样边界。原整段配音模式仍可能在工程结束处截尾，只有逐镜头模式执行绑定保护。

预览仍先生成完整代理文件，不是实时多轨引擎。60秒长样本的声音稳定性属于前轮整段模式证据，本轮没有把14.2秒实拍验证写成60秒逐句实拍验收。
