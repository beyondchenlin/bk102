# 桌面句子、配音、分镜与贴片规则

> desktop.21 更新：本页保留当时规则/差距快照。分割、删除中段、撤销重做、独立保留配音和分镜文字绑定已实现；当前行为与实际验收见 [桌面基础剪辑实现与验收](copy-edit-basic-editing-implementation.md)。原先以配音长度限制视频的规则已取消。

2026-11-08 最小实现。插件内扩展工程字段与媒体计划，不改 DSH/DSHA 宿主或 Android。

## 绑定与声音

- 一条主轨镜头以稳定 clipId 绑定一句文案快照和可选的一段配音。保存文案新版本不自动覆盖已绑定的文字；重新选择句子才更新。镜头顺序与文案库顺序独立。
- 配音有“整段配音”和“逐镜头配音”两种明确模式。旧工程默认整段模式，保持原有声音。切换模式保留另一模式的设置，不能同时叠加两套配音。
- 逐镜头配音可使用单句文件，或手动标记长录音中的起止时间；时间保存在源音频时间轴上，不跟随视频入点变化。不自动识别句子、不自动变速、不补画面冻结。
- 每句声音从对应镜头的起点播放，完整播完，剩余镜头时长静音。配音长度向上取整到 30fps 工程帧，作为镜头最短长度。数值裁切、拖拽、替换和启用逐镜头模式均执行同一后端检查。过短操作原子拒绝，不产生半次编辑。
- 裁切视频入点只改变选取的画面，配音不被一起裁掉。裁切出点不能越过配音最短长度。前面镜头时长改变，后面镜头及其配音起点一起移动；前后移同理。
- 替换素材保留 clipId、句子、配音和原镜头时长预算。新素材不足时可缩短，但不能短于绑定配音。删除镜头同时删除该镜头的绑定，不删除音频素材。操作按钮明确为“删除镜头及配音”。
- BGM 只有一条全工程音轨，从工程 0 开始循环，最终在工程结束处截断；不因镜头边界重新起播。保持原音量和立体声混音、限幅延迟补偿。
- 用户手动标记的音频范围是执行依据：系统能保护这段范围完整播放，不能保证手动边界没有切在字音中。提供“试听此句”辅助确认。自动断句对齐、停顿和跨镜头配音不属于本轮。

## 贴片

- 多行透明 PNG 内容与画布变换分开保存。位置 x/y 和宽度以 1080×1920 工程坐标表示；旧贴片默认 x=0、原 y、宽1080，读取不补写。
- 静帧画面中直接拖动，松手保存一次；Esc/失焦取消，方向键移动1像素、Shift+方向键10像素。右侧可精确调整横向、纵向、宽度，并复位。
- 允许部分移出画布，中心限制在画布内；画布外部分被裁掉。预览和1080P导出使用同一变换。连续预览时先点“调整贴片”回到静帧再编辑，避免给已合成视频重复覆盖贴片。
- 编辑贴片文字重新生成 PNG 时保留工程当前变换，避免文案页缓存的旧位置覆盖剪辑页的新位置。

### 多文字显示区间（desktop.19）

- 每条文字拥有稳定 stickerId，独立保存内容、PNG、变换和工程显示区间；最多 30 条、每条最多 4 行。宽度调整按 PNG 原比例缩放，不分别拉伸文字高度。
- 新增文字默认覆盖当前选中的镜头，随后区间独立保存，不自动绑定 clipId。裁切、替换、重排视频不改写文字时间；需要重新对齐时选中目标镜头，点“覆盖当前镜头”。超出片尾的区间不渲染，但保存原设置以便恢复工程长度。
- 时间存储采用工程 30fps 的零基半开区间 `[startFrame,endFrame)`；属性面板显示一基开始帧和包含的结束帧，不能产生空区间。两端拖动按工程帧吸附，左右键微调一帧、Esc/失焦取消、松手提交一次。源视频逐帧仍使用自己的 PTS，25fps 源帧不替代文字时间边界。
- 区间重叠时，在时间轴自动分行以便选择；画面合成顺序按添加顺序，后添加的在上层。列表/轨道选择某条文字后，在画布移动该条，不影响其他文字。
- 旧 `sticker` 字段只读时不变，首次修改转换到可选 `stickers` 数组；旧全片贴片使用 `endFrame:null` 跟随片尾，第一次手工裁时间后变为固定区间。新宿主拒绝旧的整块覆盖命令对多贴片工程写入。
- 预览与导出共用多层 PNG 和显示区间，旧缓存通过 `desktop-ffmpeg-av4` 区分。已完成成片不删除。多贴片工程不支持直接降级到只识别单贴片的旧插件继续编辑；兼容保证指旧工程升级读取。

本轮实际检查见 [多文字贴片验收](copy-edit-multi-sticker-report.md)。

## 兼容与验收

保留 schemaVersion 2，所有新增字段可选。读旧库不迁移、不改写；旧成片保留，通过 renderVersion 防止误用旧渲染缓存。校验覆盖绑定保护、重排、不同帧率替换、持久化、贴片坐标、真实 FFmpeg 混音和浏览器拖动/播放/导出。最终执行结果另见验收报告。
