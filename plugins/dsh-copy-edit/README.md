# 文案剪辑：桌面与手机适配

**交互方向修订（2026-11-12）**：默认通过创作对话确认文案并按已保存偏好生成可编辑工程，文案库提供一次点击的“生成视频”入口；复制选片信息、粘贴和输入口令降为高级导入路径。当前代码尚未接入完整对话编排与 TTS，不能将既有人工导入测试当作该体验已实现。用户路径、默认值、执行能力和验收标准见[对话式文案到剪辑](../../docs/product/conversation-to-edit-20261112.md)。

0.2.0-mobile.31 修复新添加视频默认仅取前4秒及原声被移除的问题：完整添加，最长10分钟工程；镜头属性提供“使用完整素材”和原声音量。播放源帧计数随当前播放位置更新。Android预览直接在360×640画布合成；原声音轨按窗口相位裁切，分割不重复音频。完整验收与性能边界见 `docs/product/copy-edit-mobile31-source-audio-20261112.md`。

开发分支新增素材库草案导入契约：能力查询、整份准备、原子提交和回执查询；已验证 30 秒／7 镜头四轨导入、编辑与保存重开。新增代码尚未发布为 APK。[T01 协议、两轮 review 和实测范围](../../docs/product/bk-media-library-t01-20261111.md)。

素材库选片可从首页“导入选片”生成新候选：粘贴素材库复制的信息并输入其独立口令，选择配音和 BGM 后按已登记原视频真实帧映射导入。未选择的音轨明确为空；贴片、镜头和音轨仍可在工程中编辑。导入时的名称差异与帧边界变化保留为提醒；素材不足的替换不会静默缩短导入工程。跨源配置与恢复说明见素材库的 `docs/architecture/bk-media-bk-import.md`。本功能未部署到生产宿主或 APK。

0.2.0-mobile.21 使用统一的手机尺寸变量：导航、分类、操作和底部栏为40px，界面文字13px，轨道基础行高40px；阅读正文16px。容器只计一次边框，预览吸收剩余高度。移除重复的已保存说明、字数和工具宣传提示；选中音轨后属性区直接显示该片段。

视频、文字贴片、配音及BGM均可按工程播放位置分割；分割和删除作用于选中轨道，支持撤销、重做。BGM保留48kHz源采样相位和有限时间区间，配音保留源入出点；连续配音在Android执行时合并解码，界面片段仍独立。新音轨计划使用schemaVersion2和segmentedAudio能力检测，旧原生提供方明确提示升级，不静默漏播。文案页能识别分段音乐并进入剪辑调整。

持续设计原则：像Linear与苹果备忘录一样干净，目标、架构、设计和实现都简单。删去标语、重复提示和次要标签；靠布局表达操作关系。每次改动同时考虑UX、DX、AX：共用尺寸与时间模型、保留可访问名称、可逆命令和数据兼容。历史标题只保留为兼容元数据，展示名称始终来自正文首句。

0.2.0-mobile.17 统一手机控件密度：顶部栏 48px，底部剪辑工具改为单行，按钮底色 32–36px、实际点击高度保留 44px。底栏“属性”包含声音设置，完整无障碍名称保留。文案工具行、正文和间距与宿主 12/13/14px 层级协调，进入剪辑收为右侧紧凑按钮。沿用 mobile.14 的首页与时间轴修正；选中视图的底色也遵循紧凑尺寸。

0.2.0-mobile.12 移除桌面与手机的独立文案标题，侧栏、首页、工程选择及分类提示统一采用当前正文首句；无句末标点时采用第一行，空正文显示“空白文案”。未保存副本收进原有版本菜单，不再占用独立一行。切换已保存版本前保护当前草稿；修改后菜单显示“草稿”，可重选原版本并找回修改；只查看已保存版本不反复增加恢复副本。历史标题元数据、版本与恢复副本均保留。沿用 mobile.9 的简洁文案与剪辑布局。该版本仍为隔离外观评审版，Android播放与WebView内核稳定性尚未完成验收。

原生媒体提供方通过同源主帧 `DshaCopyEdit` 消息桥探测。可用时，素材原始字节经已有认证路由流转，Android执行索引、精确取帧、预览缓存和AVC/AAC导出；页面只传工程/修订/摘要/任务身份。开始请求超时后只查询原任务，不自动改用桌面重发。原生会话离开前台取消任务；新页面/进程不恢复旧导出。分享调用系统选择器，文件流读取和播放支持有界Range。

共享模块在 `components/copy-edit-media`，Standard宿主源码已接入，但 `HOST_DEVICE_VERIFIED=false`，当前生产能力默认关闭；Low不包含Media3。独立API30模拟器已验证素材→工程→导出、桥与取消等路径，完整生产手机、ARM64性能、连续预览稳定性与系统UI验收仍有缺口，详见 `docs/product/copy-edit-mobile-progress.md` 和验收矩阵。模拟器WebView83不能解析上游DSH入口的逻辑赋值/静态块；本插件完整client在该内核可解析。不能据此宣称生产手机已经可用。

原生按已索引源PTS映射到30fps工程，最长10分钟、1080×1920导出/360×640预览、最多30个1080×400透明PNG；原声、配音和BGM按同时活跃音轨统一预留峰值。单素材256MiB、会话素材512MiB，精确帧缓存64张/32MiB。Windows提供方及其较宽的素材范围保持原规则。

视频裁切、分割、删除、替换和重排默认保留完整配音，首次操作时把当前发声的配音固定为独立音轨。分割关联多个画面仍只播放一次配音；可以在独立配音面板修改开始帧、源范围、音量或明确删除。视频不再受配音最短时长限制。声音超过画面末尾时显示“只有声音，需补充画面”，预览与导出保留完整声音并输出黑色画面尾段，BGM 按工程时间连续播放。

文字可绑定分镜或固定在时间轴。新建默认绑定选中镜头；移动跟随、头部裁切调整局部时间、替换保留对应关系、分割把跨界文字拆为两段并保持层级；删除片段同时移除其绑定文字，撤销可恢复。绑定文字手动时间限于对应镜头，取消绑定后可跨镜头显示。旧固定时间文字保持原行为。分割保存共同解码窗口，避免 25fps/VFR 素材分别取整添帧；替换保留输出帧预算，包括比源帧时长更短的片段。

历史 desktop.15 的声音规则（desktop.20 已取消视频最短配音限制）：声音面板可选“逐镜头配音”：每个 clipId 绑定文案快照与单句音频或手工指定的音频起止段。裁切/替换不能短于完整配音，失败不改工程；移动镜头连同绑定一起移动，前镜头缩短后后续配音一起前移，BGM 继续按全工程时间播放。切回整段模式保留两种模式设置，只有当前模式发声；旧工程默认整段模式。文案新版本不覆盖既有绑定。没有自动语音断句，也不自动改速或补冻结帧；手工范围需试听确认。延迟后重建样本时间戳，规避已验证的旧 FFmpeg adelay/apad/时间裁切组合异常。规则见 `docs/product/copy-edit-binding-rules.md`。

desktop.14 在混音前统一为 48kHz 立体声，保留 BGM 左右声道，补偿限幅器的前瞻延迟。结果带渲染语义标识，旧引擎结果保留但不作为新预览缓存，避免升级后旧预览与新导出音频不同。配音和 BGM 都锚定工程第 0 秒：裁切/替换视频不会自动重排配音句子；配音不足时补静音，BGM 循环，末尾按工程长度截断。预览和导出使用相同混音，真实 FFmpeg 回归需要设置 `COPY_EDIT_FFMPEG` / `COPY_EDIT_FFPROBE`。desktop.12 已将替换出点改为按源 PTS 和原时长计算，避免沿用不同素材的帧号。

针对 DSH 0.2.1-rc.2。侧栏「文案剪辑」进入文案或剪辑，支持文案不可变版本、手动导入、源帧裁切与替换、PNG 贴片、配音/BGM、连续预览与 1080×1920 / 30 fps 导出。当前桌面提供方仅启用 Windows，使用 DSH Host 上的原生 FFmpeg；远程手机打开页面仍是电脑编码。

复用依赖后运行 `npm run test:contract`、`npm run typecheck`、`npm pack`。新环境用锁文件执行 `npm ci`。安装使用 `dsh plugin --profile web add <绝对 tgz 路径>`；开发验收使用隔离 DSH_HOME。FFmpeg 不打进插件，不修改系统 PATH：在启动 DSH 的进程设置 `COPY_EDIT_FFMPEG` 与 `COPY_EDIT_FFPROBE` 为本机二进制绝对路径，或使用已有 PATH。缺失时文案可用，媒体能力返回不可用。首次校验使用 FFmpeg 2024-06-09 git94f。

数据只写 DSH_HOME/copy-edit。素材以摘要寻址，工程保存句柄，不暴露主机路径。PNG 由浏览器实际栅格化，透明、多行、描边、背景进入最终成片。打开完整示例工程会建立可编辑副本，包含两段自制色块、贴片和提示音，提示音不冒充 AI 配音。

服务：`copyEdit/workspace`、`create({request:{title,operationId}})`、`mutate({request})`、`render({projectId,revision,profile})`、`job({jobId})`、`cancel({jobId})`、`example({sticker})`、`describe({projectId})`。`project` 保留历史只读接入样例。新建工程支持同操作重放且不覆盖旧工程；过期重放依据确定工程身份拒绝重复创建。工具 `copy_edit_describe` 与 UI 使用同一服务。类型见 contracts/media.d.ts。大文件经 DSH connection.fetch 的已认证流式路由，不开旁路端口。

预览先生成 360P 代理，然后用单播放器连续播放；修改后准备新代理，并非实时多轨引擎。静帧通过源展示索引解码，前后逐帧与连续预览分开。输出以实际解码帧数校验后提交，取消不替换旧成片。活动任务在停用时取消，已完成结果重开仍可读。

Windows提供方范围：单主视频轨拼接、SDR、10 分钟以内、120 个镜头、120 个文字贴片、单素材 512 MiB/10 分钟以内。音频包括源视频原声、导入配音与循环 BGM，镜头可独立静音。字幕/额外叠加轨尚无完整编辑能力。版本最多 200、素材 200、工程与结果各 100；当前没有库清理 UI。草稿尽力持久保存，明确保存的版本仍是工程正文的提交依据。
