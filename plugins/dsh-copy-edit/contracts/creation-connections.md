# 创作连接与执行契约

这是部署配置，不是每次创作时让用户填写的表单。管理员在宿主连接一次素材库和配音服务，保存到 `DSH_HOME/copy-edit/connections.json`，或以 `DSH_COPY_EDIT_CONNECTIONS` 指向独立私有文件。示例见 [creation-connections.example.json](creation-connections.example.json)。文件限制32KiB，拒绝符号链接；权限应仅允许运行工作台的账号读取。真实配置、令牌和媒体不进 Git 或插件包。

素材库使用当前 `/v1/plans` 及其版本化导出合同，令牌仅由宿主附加。地址只接受 HTTPS 原点或本机 HTTP 原点；禁止重定向与 URL 凭据。手机宿主的 `localhost` 是手机自身，远程服务必须配置手机可访问的 HTTPS 地址。

配音适配器向配置的固定 endpoint 发送 JSON：`{model, voice, input, speed, response_format:"wav"}`，要求返回完整 RIFF/WAVE 文件。单句最大10MiB；媒体登记再次解析实际音频。参考音频克隆尚未实现；仅有参考音频而没有服务音色ID时，不当作已配置成功。已保存音色的服务/模型与连接不一致时不调用其他服务。

`speech.idempotent` 默认 false。只有服务端明确实现了 `Idempotency-Key` 去重、相同请求返回同一产物的合同，才能配置 true。完整响应先落盘再登记，正常恢复复用它；服务回执不确定且不支持幂等时，保存状态并询问是否重试该段，不自动重复付费请求。

`defaults.musicAssetId` 是本工作台已登记的音乐资产；明确无音乐时设 null。省略代表未选择，首次生成集中询问。不能随意取音频库第一条当作BGM。用户通过对话补充声音/音乐选择；只有明确要求记住时写入长期默认值。文案页明确选择无音乐优先于部署默认值。

执行顺序：保存文案和意图 → 固定偏好 → 按句实际配音 → 根据音频时长请求选片 → 目标端登记媒体 → 绘制可编辑首句标题 → 四轨原子提交。无旁白时使用 `targetFrames`（默认300帧）。选片接口当前最多900帧/30秒、32句、每句200字；普通剪辑的10分钟上限不能替代选片限制。标题采用首句，不声称已生成逐字字幕。

对话工具：`copy_edit_context` 读取上下文；`copy_edit_confirm` 的 `copy` 意图只保存，`video` 意图创建任务；`copy_edit_task` 查询、暂停和继续。工具说明随插件注册，要求先有视频意图和完整文案确认，不把普通文案讨论自动变成视频任务。文案库和正文页“生成视频”调用同一入口。

宿主保存任务、租约和每步产物，已登录的工作台页面执行媒体登记。桌面使用已配置的 FFmpeg；Android 使用原生媒体桥。关闭文案剪辑面板仍可在对话页执行；退出整个工作台或手机页面失效后需回到可用页面继续，不能承诺后台持续编码。多个页面不会重复领取同一个有效租约。暂停与最终提交在同一存储串行锁下核对，已经完成的工程不会被重试覆盖。

配音真实时长先向上量化为工程帧，每句仅补不足一帧的尾部空隙，不截断声音。素材库缺片/时长不足会保留文案与配音并说明问题；现有冻结选片不会因重试被换成其他版本，补充素材或改文案后可明确生成新一版。可用画面存在描述差异时，结果保留核对提示。
